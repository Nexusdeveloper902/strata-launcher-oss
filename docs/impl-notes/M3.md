## Manifest / permissions
- **No new `uses-permission`.** `config/approved-permissions.txt` unchanged.
- New component (merged from `:platform:system`'s manifest): `LockAccessibilityService`, `exported="false"`, guarded by
  `BIND_ACCESSIBILITY_SERVICE` (a service guard, ANDROID_PLATFORM §23), XML config with no event types, no window
  content, `isAccessibilityTool="false"`. D-011 includes the lock in the personal build, so there is still no
  `lock`/`nolock` flavour; it is gated at runtime by `lock_gesture_enabled` (settings field 23) and API 28+.

## Choices where the spec left room (owner may want to revisit the ones marked ★)
1. ★ **Lock gesture shipped in M3** (ROADMAP lists FR-GEST-03 as v1.x; D-011 includes it). Settings toggle → our
   disclosure dialog → system accessibility settings. The "turn on screen lock" hint shows **once per process**
   (no settings field exists for "shown"); the home-root a11y action "Lock screen" appears while the toggle is on.
2. ★ **Home menu Widgets / Themes and sheet "Change icon"** are present (TEST_PLAN requires them) but show a
   snackbar "… arrive in a later version" until M7 / M5. App shortcuts in the sheet are M6 (not shown).
3. ★ **Favourites cap counts shown favourites only**: a hidden or uninstalled favourite keeps its slot (T-APPS-06
   "slot kept for restore") but does not block a new one. Stored rows may therefore exceed 12.
4. ★ **"Add favourites" (empty home)** opens FAVEDIT, which lists every other app with "Add" below the current
   favourites (doubles as the picker until M6's onboarding picker). Back and Home in FAVEDIT **save** (J-07);
   there is no "save changes?" prompt.
5. **Home press** goes to HOME_REST in one press from any state (INTERACTION_SPEC §3 wording), in the §6 order.
6. **Clock styles**: `numeric`, `numericStacked`, `analogMinimal`; `words` falls back to `numeric` (allowed by
   VISUAL_SPEC §9.4). Date via `DateFormat.getBestDateTimePattern(skeleton)`.
7. **Sheet** is drawn in the home window (not a dialog) so it survives config changes (FR-LIFE-02); predictive back
   drags it down. Rename: inline field, 60-char limit enforced on input, Save disabled when blank; "Reset name"
   separate item.
8. **Gestures**: swipe-up detector on the home root in the Main pass (ignores consumed gestures, so a scrolling
   favourites block or the index wins); long-press / double-tap on a background layer that only gets empty-space
   touches; a move beyond touch slop cancels them without consuming. Overflowing favourites hand leftover upward
   scroll / fling to search through nested scroll (rule 4).
9. **Home index** (`visibility = always`) opens the list at the letter; the scrub continues on the home index, so
   the list's own index shows no active state / bubble during that gesture.
10. **Gesture exclusion** only while the activity is RESUMED; full index rect, or 200 dp around the last touched
    letter + 16 dp inward with "Keep back gesture on index side".
11. **Rotation**: `SCREEN_ORIENTATION_PORTRAIT` below sw 600 dp unless "Allow rotation"; else UNSPECIFIED.
12. **Spoken labels**: the row node carries the original-case label as its first content description; tag and
    secondary line add descriptions, so TalkBack reads "Nav, 2 notifications" / "Mail, Work, Hidden".
13. **Settings page (M3 part)**: groups Home, App list, Search, Gestures (incl. "Vibration feedback" = haptics
    master), Apps (Hidden apps), Privacy (pause / clear history). Full graph and T-SET-02 order are M8.
14. **Icons**: no shape clipping, packs or tint yet (M5); the system icon is drawn as delivered. Work-profile rows
    use the system badged icon and skip our work glyph when a system icon is shown.
15. **T-PRIV-05**: the backup rule files do not list an explicit `<exclude>` for `launch_log.db` (lint rejects
    excludes outside includes, M0 note); the test checks the DB is under `noBackupFilesDir` and no include covers it.
16. Use cases live in the repositories (no separate `HideAppUseCase` classes); the same VM actions serve the
    sheet and the custom actions.

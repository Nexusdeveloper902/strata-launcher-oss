# M6 implementation notes (part 1: onboarding, default home, pin requests)

ROADMAP M6 is split. **Part 1** (this note) covers the first-run flow (FR-ONBOARD-01…04), the set-default logic with
its denial, retry and OEM-help paths, the APP_MODE / lost-default banner, the settings "Default home" and "Uninstall
Strata" rows (FR-SET-02), and the PinRequestActivity shell (T-SEC-02). **Part 2** covers app shortcuts in the sheet
(FR-APPS-08 v1), the work-profile section with pause/resume (FR-APPS-09) and the private-space container
(FR-APPS-10, FR-SEARCH-03 private part). Everything here is `Proposed` where `spec/` left room; change it with a
decision if needed.

## Choices where the spec left room (Proposed)
1. **Split.** Part 1 = onboarding, default home, settings rows, pin shell; part 2 = shortcuts, work profile, private
   space (they share the profile/shortcut platform work).
2. **Screens.** Welcome (privacy promise) → Pick favourites → Set as default → Done ("Go to home"); "Step n of 4" on
   each. Back moves one step back; on Welcome it leaves the entry activity, and does nothing on home (INTERACTION_SPEC
   §3: Back leaves onboarding only after the flow ends). "Not now" on the set-default step or on a card ends the flow
   (`onboarding_done` = true) and home shows the APP_MODE banner. A role granted by an attempt moves to Done on its
   own; a role held from the start shows "Strata is your home app" with Continue (T-ONBOARD-09).
3. **Picker.** Shown apps only (hidden apps are not offered), in list order, with a plain case-insensitive label filter
   (not the search index). Picks are stored in pick order on Continue via `FavoritesRepository.add`; existing
   favourites are kept. A 13th pick is refused with a polite live-region note. Step, picks and query live in the
   `SavedStateHandle`.
4. **Silent refusal.** A role request returning `RESULT_CANCELED` in < 2 s (time between launch and result, measured
   with `elapsedRealtime`) is treated as "don't ask again": the settings chain opens at once and every later attempt in
   the process goes there directly. The flag is per process (no settings field exists for it); a new process costs one
   silent bounce at most.
5. **OEM help card** appears after RESULT_OK without the role, after any settings-chain return without the role, and
   when no screen of the chain exists. It is shown once per attempt (dismissed by Not now / Retry; a resume does not
   bring it back). The known-blocking note uses `OemDetector`: Xiaomi/Redmi/POCO and an `OS<major>.<minor>` token with
   major ≥ 2 in `Build.VERSION.INCREMENTAL` or `Build.FINGERPRINT` (heuristic, U-016).
6. **Banner.** One banner for APP_MODE: "Strata is not your default home app…" [Dismiss] [Set as default], or, once
   the role was held earlier in this process, "Strata is no longer your home app." [Dismiss] [Set again]. Never shown
   during onboarding. Dismiss stores `default_home_banner_dismissed_until = now + 24 h` (field 19); the banner is hidden
   while the last role check (every `onResume`) is before that time. The banner's and the settings row's attempts show
   the Denied / OEM cards as dialogs.
7. **Settings rows.** A new "Home app" group at the top of the settings root (FR-SET-01's group list has no place for
   it; T-SET-02 order is M8): "Default home" with the status as summary, "Uninstall Strata" with a one-line hint. Tap
   on "Default home" while Strata is home opens the home settings (to change it).
8. **Uninstall Strata** while Strata is home: guidance dialog ("Choose another home app first" → [Open home settings]);
   the home settings chain is started for a result; on return the role is re-checked and the system uninstall dialog
   (`ACTION_DELETE` for our package) opens only once Strata is no longer home, else the guidance shows again.
9. **PinRequestActivity** (exported, both `CONFIRM_PIN_*` actions, `excludeFromRecents`, `autoRemoveFromRecents`,
   translucent `Theme.Strata.Dialog`, plain `Activity`). A valid request is declined in v1 (no `accept()`, a short
   toast "Strata can't add items to home yet"); anything else finishes in `onCreate` with no UI.
10. **Device tests and the owner's pass.** Tests that need a human in a system dialog are gated by the instrumentation
    argument `strata.manual=true`; on CI they skip. All device tests restore `onboarding_done` and field 19.

## Manual checks on the Galaxy A56
- Fresh install (`adb shell pm clear app.strata.launcher`), open the icon: 4 screens, no permission prompt; pick 3
  favourites; "Set as default" → One UI's home-app dialog → accept → Done → home with the 3 favourites.
- Deny the dialog → Denied card; deny again with "Don't ask again" (if One UI shows it) → "Try again" opens the
  default-apps settings directly, no loop. Choose Strata there → back → Done.
- Settings › Apps › Default apps › Home app → One UI Home; return to Strata via its icon: "no longer your home app"
  banner; Dismiss; reopen: hidden; Home key opens One UI Home.
- Strata settings › Uninstall Strata: guidance → home settings → pick One UI Home → back → the system uninstall dialog
  (cancel it).
- Run the manual-gated device tests: `./gradlew :app:connectedDebugAndroidTest
  -Pandroid.testInstrumentationRunnerArguments.strata.manual=true
  -Pandroid.testInstrumentationRunnerArguments.class=app.strata.launcher.onboarding.OnboardingDeviceTest`.

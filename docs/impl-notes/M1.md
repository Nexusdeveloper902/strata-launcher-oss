## Choices where the spec left room
1. **Repository interfaces in `:core:platform-api`** (`SettingsRepository`, `AppCatalog`, `AppListSource`,
   `LaunchLogRepository`, `ResetNotices`), implementations in `:core:data`, so `:testing:fakes` stays pure JVM
   (same reasoning as M0's `OnboardingStore`, which is now deleted).
2. **Settings writes are sparse**: `update` writes only fields whose value changed, so untouched fields stay absent.
   `install_id` (field 2) is set by a DataStore migration when absent or not a UUID v4. Unknown enum values read as
   the default; `catalogue_version < 1` and negative `default_home_banner_dismissed_until` are clamped.
3. **M0 → M1 migration**: `entry_flags.bin` (2 bytes) is read by a DataStore migration; `true` becomes field 3,
   then the file is deleted (also when unreadable).
4. **Corruption** (FR-LIFE-04): settings → `ReplaceFileCorruptionHandler` + banner. `strata.db`: header sanity
   check (magic, page size, truncated vs. header page count) before open; open/migration failure (incl. unknown
   newer version) → close, move to `filesDir/quarantine/<ts>-strata.db`, recreate, banner; SQLite's own corruption
   callback copies the file to quarantine before its default delete. `launch_log.db` is deleted instead (no banner).
   The banner is in-memory per process (`ResetNoticeBoard`). `PRAGMA quick_check` once per app update is **not**
   done yet.
5. **Catalog**: full reconcile on start/`onStart`/launch failure/profile broadcasts; per-package reconcile on
   `LauncherApps.Callback`. The new state is published before the snapshot write. Overrides are marked missing only
   for profiles that were actually read (a paused work profile does not start the 30-day purge clock).
   Quiet-mode and private-space profiles are skipped until M6 (their rows disappear while paused).
   `last_update_time` = `lastModified()` of the APK file (no per-package `PackageInfo` IPC); `SYNTHESIZED` = class
   `android.app.AppDetailsActivity` (Inferred).
6. **Sections**: ICU underflow bucket is shown as "#" and placed **last** in the list and the index
   (**owner decision**, after M1 review; ICU itself orders it first); other ICU labels and their order are kept,
   including the overflow "…" bucket for scripts outside the locale's index. For a single non-Latin locale
   (ja, ru, ar) Latin labels therefore land in "…" (see goldens); real devices usually list `en` too, which adds A–Z.
   The goldens were recorded from Robolectric's ICU (`-Pstrata.recordGoldens=true`) and reviewed by hand.
7. **Duplicates** (FR-APPS-11): across profiles the line names the profile (main row says "Personal"); within one
   profile: same package → activity class name minus "Activity", different packages → package tail; full name if
   still ambiguous.
8. **Index**: one tick per letter *change*; the touch-down jumps without a tick (T-LIST-04 counts 25 for A→Z).
   Letter = linear position on the track, so folded ("•") slots still reach every letter. The bubble shows the
   section the list jumped to (Q → R). Index visible unless `alphabetIndex.visibility = never`.
9. **Two columns**: by window width (≥ 600 dp) and `list_two_column`; each section fills its start column, then
   its end column; a lazy item holds one line of two rows, so TalkBack reads A1, A(k+1), A2… (still section-major).
10. **Opening the list in M1**: an "All apps ›" row on the placeholder home (favourites arrive in M3). Back and
    Home return to rest. List-end "Settings" opens `SettingsActivity` with `APPLICATION_PREFERENCES`; "Hidden apps"
    uses internal action `app.strata.launcher.action.HIDDEN_APPS`, which shows the settings root stub until M3.
11. **Launch failure** text: "Couldn't open <label>" + [App info] (INTERACTION_SPEC §8 wording; TEST_PLAN accepts it).
12. **Haptics**: `ViewHaptics` performs feedback on the attached home window; gating (master switch) is in the VM.
    Theme haptics (`haptics.mode`) gate arrives with the theme repository (M4 integration).
13. Monogram tiles are decorative (no semantics); test tags double as resource ids under `HomeRoute`.

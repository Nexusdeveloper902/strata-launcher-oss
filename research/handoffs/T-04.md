Answer: An entirely free, data-only theme system: one strict-RFC-8259 JSON document per theme (`schemaVersion` 1 + additive `schemaMinor`, UUID `id`; 11 optional token groups, all defaulted, opaque `#RRGGBB` colours, unknown and `x-` keys preserved on round-trip) with per-field clamp/default/generate/truncate/reject policies, and an optional hash-verified `.strata-theme.zip` bundle for user fonts and a wallpaper. Contrast is checked against WCAG 2.2 AA on an effective background that includes the wallpaper dim. Two checks run: a static worst case over every possible wallpaper, and a runtime check against the current WallpaperColors. Render-time enforcement and an editor fix button never rewrite files on their own. Storage is app-private AtomicFile JSON plus a Proto DataStore index; last-known-good, a crash-loop guard and the compiled-in "Strata Default" theme mean a bad theme can never stop the app from booting.

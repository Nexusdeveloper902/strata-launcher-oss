| D-008 | 2026-10-29 | **Entry point and first run.** The app icon (`MAIN`/`LAUNCHER`) belongs to `SettingsActivity`, which routes: `onboarding_done` false → onboarding; otherwise an explicit intent to `HomeActivity` (APP_MODE with the "Set as default" banner if the role is not held). `APPLICATION_PREFERENCES` opens settings directly. `HomeActivity` keeps only the HOME filter and, if the system starts it before onboarding ran, shows onboarding as its first layer (the set-default step is then already satisfied). First run therefore starts at whichever entry the user reaches first; `onboarding_done` is set when the flow ends by any path. Strata's own icon is omitted from its own list. | Resolves T-07 R-01 / U-024. Keeps the home activity out of other launchers' lists (ANDROID_PLATFORM §1) while satisfying FR-HOME-01; an explicit intent needs no LAUNCHER filter. |
| D-009 | 2026-10-29 | **Theme wallpaper hand-off, no `SET_WALLPAPER`.** FR-THEME-34 hands the image to the system with `WallpaperManager.getCropAndSetWallpaperIntent(contentUri)` via our FileProvider (fallback `ACTION_ATTACH_DATA`); Strata never calls `setStream`/`setBitmap` and does not declare `SET_WALLPAPER`. | Resolves T-07 R-04 by least privilege (NFR-PRIV-03). Checked on developer.android.com 2026-10-29 (DOC-045: method added in API 19, requires a `content:` `image/*` URI; `setStream` requires `SET_WALLPAPER`. DOC-001: `ACTION_SET_WALLPAPER`, `ACTION_ATTACH_DATA`, API 1). The user also gets the system crop/confirm step. |
| D-010 | 2026-10-29 | **Launch log in its own non-backed-up database.** `launch_log.db` is a separate `RoomDatabase` stored in `noBackupFilesDir`; backup rule files also exclude it. The post-restore clearing hook is dropped. Restore is detected with a `no_backup` install marker compared with `settings.install_id`. | Resolves T-07 R-03 and R-31: NFR-PRIV-05 promises the log never leaves the device in a system backup, and Room cannot exclude single tables. |
| D-011 | 2026-10-29 | Scope: personal project, sideloaded, not distributed on Google Play.
